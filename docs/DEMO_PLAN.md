# Demo Plan

Use synthetic data only.

Narrative:

1. Show gross payments, pending settlement, refunds, fees, tax, and available cash.
2. Ask where money went.
3. Trace a payment from order to bank credit.
4. Introduce a settlement mismatch.
5. Show reconciliation exception.
6. Show late receivable risk and cash forecast change.
7. Ask the controller why.
8. Run scenario and optimizer.
9. Show a safer plan and audit history.

Final demo data must include hidden ground truth for anomalies.
